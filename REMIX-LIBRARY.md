# REMIX LIBRARY : OLD DAN KOE TWEETS, REMIXED FOR FRANCO

Source: Dan Koe's pre-fame era tweets (2019-2022, the broke-digital-artist years) : gathered from web research.
Usage: pick a row, swap the words to fit Franco's story, run it through Franco's Voice Rules (SKILL.md Section 12). Never copy Dan's words . Remix them.

## The method (SKILL.md Section 11)
1. Extract the core claim.
2. Swap the situation: Dan's corporate job -> Franco's decision to build with AI agents instead of the default path. Dan's web design -> Franco's AI agents. Dan's writing routine -> Franco's problem-first method.
3. Keep the structure, rhythm, and punch.
4. Check against the voice rules: no "not this, but that," no agency claim, no ADHD/depression confession.
5. State it as fact.

5. Keep the Dan Koe rhythm.
