# Task template

One small task framed so the AI can run with it . Describe it in plain words and paste the filled version as a prompt .

```markdown
TASK: <one sentence , what to do>
DONE WHEN: <what success looks like, checkable>
CONTEXT: <what the agent needs to know>
- <key fact 1>
- <key fact 2>
CONSTRAINTS: <what not to do>
- <constraint 1>
DELIVERABLE: <file / message / format>
VERIFY: <how we'll check it worked>
```
