# Kynd — Vision + Same-Vision Sites (with screenshots)

## What Kynd is (synthesized from the shared files + the freebuff-built site)

Kynd = **Know Yourself · Kindness · Harmony · Peace · Resonance**.
Tagline: *"Know yourself, build with intention."* / *"Community and forward momentum."*

Core beliefs:
- Anti-guru. Authority through honesty, not credentials. The hook is the gap: every AI
  community is courses or flexing, nobody helps beginners actually build.
- A **free Discord community** for people learning to build with AI agents.
  "Real questions. Real resources. No guru energy."
- The **Problem-First Method**: (1) Name one small task you do a lot. (2) Explain it in plain
  words. (3) Talk to the AI like a person, tell it what you want, iterate 3×. The more you
  solve, the more you can build. Compounding in public.
- Voice: short lines, whitespace as a signature, no "not this but that," no therapy-speak,
  state the positive directly. One CTA per post.
- Rejects the default path ("study, graduate, get hired, climb, retire") as a slow death.
- One pillar (Substack essay) → four cuts (X thread, LinkedIn, Reddit, Discord invite).
