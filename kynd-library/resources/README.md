# Resources

Curated tools, links, and references. We do not list everything — we list what a Kynd member would actually reach for. Curation over volume.

## The Tool Library (live)

The full curated tool list lives on the web as **The Kynd Library** — 70 AI-agent tools, each with what it is, what you would build with it, and what it costs. Free, no email.

- Live page: https://join-kynd.netlify.app/library.html
- Source in this workspace: `../kynd-site/library.html` (the cards are plain HTML, searchable and filterable client-side)
- Spreadsheet export: `../kynd-site/KYND_Library.xlsx`

The tools are grouped into categories. The categories themselves are a map of the agent stack:

| Category | What it covers |
|----------|----------------|
| LLM Platforms | The brains: OpenAI, Anthropic, Gemini, Groq, Mistral, together, Ollama, LM Studio |
| Agent Frameworks | How you wire agents: LangChain, CrewAI, LangGraph, OpenAI Agents SDK, Agno, Mastra |
| Coding Agents | The editors that write code: Cursor, Copilot, Replit, Windsurf |
| Voice | Speech in and out: ElevenLabs, Whisper, Deepgram, Vapi, Retell, Cartesia |
| Memory & Data | Remembering and storing: Pinecone, Chroma, Qdrant, Supabase, Mem0, Zep |
| Browser & Scraping | Web interaction: Playwright, Browserbase, Apify, Browser Use |
| Hosting | Where it runs: Vercel, Modal, Railway, Render, Cloudflare |
| Research | Grounding in the web: Perplexity, Firecrawl, Exa |
| Observability | Seeing inside: LangSmith, AgentOps, Langfuse |
| Media | Image, video, music: Midjourney, Runway, ComfyUI, Suno, Resend |
| No-code | Visual automation: n8n, Zapier, Make, Dify |
| Agent Infra | Durable execution: Inngest, Cloudflare Agents |
| Tooling | Integrations: Composio |
| General Agents | End-to-end products: Manus |

Each tool is tagged **Top 50** (we would reach for it today) or **Emerging** (promising, new, still changing). Definitions in the [glossary](../foundation/kynd-glossary.md).
