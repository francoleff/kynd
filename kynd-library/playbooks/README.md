# Playbooks

Reusable, step-by-step methods. This is Kynd's core IP — the stuff we actually use and tell members to use. A playbook is not theory. It is a method you can run today.

Every playbook here should be: clear, actionable, and grounded in something Kynd has actually done or verified.

## What belongs here

- Named methods (the [Problem-First Method](problem-first-method.md), the [Content engine](content-engine.md)).
- Decision frameworks ("which tool / which path / should you even build this").
- SOPs and checklists for repeated work.
- Prompt systems.
