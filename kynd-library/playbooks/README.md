# Playbooks

Reusable, step-by-step methods and decisions. This is Kynd's core IP — the stuff we actually use and tell members to use. A playbook is not theory. It is a method you can run today.

Every playbook here should be: clear, actionable, and grounded in something Kynd has actually done or verified.

## What belongs here

- Named methods (the [Problem-First Method](problem-first-method.md), the [Content engine](content-engine.md)).
- Decision frameworks (the [should-you-use-an-agent filter](should-you-use-an-agent.md)).
- Discipline playbooks ([QA discipline](qa-discipline.md), [building skills](building-skills.md)).
- SOPs and checklists for repeated work.
