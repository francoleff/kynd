# The Kynd Library

Kynd is a free community of builders. The Library is the operating system we hand you: a place to **understand, learn, decide, build, execute, and improve** with AI agents — without the courses-and-flexing noise.

This is not a blog. It is a working knowledge base. Every page exists to make you a better builder. If a page does not do that, it does not belong here.

## How to use it (the loop)

Start anywhere, move in a loop:

```
UNDERSTAND  →  LEARN  →  DECIDE  →  BUILD  →  EXECUTE  →  IMPROVE
   ↑                                                          │
   └──────────────────────────────────────────────────────────┘
```

- **Understand** — what is this thing, in plain words.
- **Learn** — the concepts and skills behind it.
- **Decide** — is this the right tool, path, or move for you.
- **Build** — actually make something.
- **Execute** — ship it, run it, use it in real life.
- **Improve** — review what worked, capture it, go again.

You do not read the Library front to back. You enter at the problem you have right now.

## How this Library is organized

- **Pages link to pages.** A concept points to the tool that uses it, the playbook that builds it, and the case study that proves it. That is the knowledge graph — not a menu, a web.
- **Every area has a `README.md`** that says what belongs there and what is still wanted. Empty areas are seeds, not finished pages.
- **We improve instead of duplicating.** If a page exists and is weak, we make it stronger. We do not create a second one.
- **No fabrication.** Tools, prices, and claims come from sources we trust or from Kynd's own work. If we are not sure, the page says so.

## The Kynd standard

Every page here is held to one question before it is published:

> Would this actually help a capable person do something better?

If not, it does not ship. We optimize for useful capability, not page count.
