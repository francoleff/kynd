# Frontier

What is new, what is shifting, and what a builder should watch. This area is volatile by design — tools here are tagged **Emerging** in the [Tool Library](../resources/README.md) and can change or die in a quarter. We keep it honest: promising, not proven.

## What belongs here

- New agent capabilities and architectures.
- Shifts in the tool landscape (a category consolidating, a new category forming).
- Things Kynd is experimenting with before they are "done."
- Short notes, not essays. A frontier page can be three sentences and a link.

## How to read it

Treat frontier entries as scouts, not recommendations. The stuff that survives gets promoted into [Foundation](../foundation/README.md), [Build](../build/README.md), or [Resources](../resources/README.md).

## Seed entries (from the Emerging tier)

- **OpenAI Agents SDK / Agno / Mastra / smolagents** — the lightweight framework wave. Less boilerplate than LangChain; picking one is a [decide](../playbooks/README.md) problem.
- **Browser Use / Stagehand** — agents that drive the web by natural language. Closes the gap between "I can code a scraper" and "I just described what I want."
- **Voice agents (Vapi, Retell, Cartesia, Bland, LiveKit)** — real-time voice is finally low-latency enough to be usable. Phone-call automation is the obvious first wedge.
- **Memory layers (Mem0, Zep)** — agents that remember across sessions without you re-explaining. The missing piece for long-running personal agents.
- **Cloudflare Agents / Inngest** — durable, stateful execution at the edge. Matters once your agent has to run for real, not just in a demo.
